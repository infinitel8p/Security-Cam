# Bluetooth Setup

## Pairing

Ensure your Bluetooth device's visibility is turned on, then run the included pairing script:

```bash
chmod +x /opt/security-cam/tests/pair_bluetooth.sh
/opt/security-cam/tests/pair_bluetooth.sh
```

The script will scan for nearby devices, list them, and let you pick one to pair and trust.

:::info
If you prefer to do it manually, you can use `bluetoothctl` directly:

```bash
bluetoothctl
```

In the prompt:

```bash
agent on
default-agent
scan on
```

Once you see your device's MAC address:

```bash
pair XX:XX:XX:XX:XX:XX
trust XX:XX:XX:XX:XX:XX
exit
```
:::
